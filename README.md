# Brain Connectivity Graph Viewer

**Status:** 🚧 Actively in Development (August 2025 - Present)

### Vision
A full-stack web application to visualize 3D brain connectivity graphs derived from neuroimaging data. This tool allows users to interactively explore network topology by filtering connections based on weight and hovering over nodes to identify anatomical regions.

### Core Technologies
* **Backend:** Python, FastAPI, Pandas
* **Frontend:** React, JavaScript, Three.js (for 3D rendering)
* **Database:** PostgreSQL (Planned)
* **Deployment:** Docker, AWS EC2
